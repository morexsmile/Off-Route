# OFF ROUTE
Donde termina el mapa, empieza la aventura.

OFF ROUTE es una landing page conceptual para una agencia de viajes especializada en aventuras poco convencionales y destinos fuera de las rutas turísticas habituales.

El proyecto está diseñado como una pieza de portfolio frontend, buscando transmitir una identidad visual editorial inspirada en mapas, expediciones, fotografía documental y señalética de viaje.

Proyecto
OFF ROUTE propone una forma diferente de descubrir el mundo: experiencias de aventura organizadas por destino, tipo de experiencia y nivel de adrenalina.

La web incluye:
- Hero principal con llamada a la acción
- Explorador de aventuras
- Aventuras destacadas
- Destinos internacionales
- Niveles de adrenalina
- Sección "Cómo funciona"
- CTA final
- Footer con navegación y redes

Diseño
La identidad visual está inspirada en:
- Mapas y coordenadas GPS
- Revistas de viajes
- Carteles de expediciones
- Fotografía documental
- Señalética
